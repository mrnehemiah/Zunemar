# ZUNE Marketplace — Premium Modern

Responsive, mobile-first ZUNE Marketplace frontend using browser ES modules and Supabase.

## Source layout
- `src/app` — application entry point
- `src/components` — reusable UI components
- `src/config` — public configuration and feature flags
- `src/pages` — page renderers
- `src/services` — data services and Supabase integrations
- `src/styles` — design system and responsive CSS
- `assets` — brand assets and image placeholders
- `supabase` — optional Edge Function source
- `docs` — setup, architecture, security and full file-by-file audit
- `tests` — manual smoke-test checklist

Read `docs/FILE-BY-FILE-AUDIT.md` before deployment. Supabase schema was not changed. Seller approval remains controlled by ZUNE PREMIUM ADMIN. Payments remain disabled. Demo mode is for preview only.
